QuestBuddy

v0.1.0 · Windows

A system-tray companion for Hollow Knight and Silksong. Track progress, explore stats, edit saves — all from a sleek desktop app.

⬇ Download View Source

Features

Save Detection

Automatically reads Hollow Knight and Silksong saves with built-in AES-256 decryption.

Progress Stats

Geo, soul vessels, grubs, nail upgrades, charms, bosses, dream essence — all in one view.

Next Steps

Smart suggestions based on your current save to help you decide what to do next.

Save Editor

Browse and edit raw playerData fields directly from the app.

8 Themes

Dark, Purple, Light, Forest, Ocean, Amber, Rose, and Slate — pick your favourite.

Tray Integration

Minimizes to the system tray. Close hides to tray, right-click to quit.

Themes

Dark Purple Light Forest Ocean Amber Rose Slate

Installation

Download the latest installer from the releases page, run it, and you're ready to go. No additional dependencies needed.
